Kebijakan Privasi SmartEyeX

Diperbarui 6 Oktober 2026 · Berlaku untuk aplikasi Android SmartEyeX (com.xnvalabs.smarteyex)

SmartEyeX tidak punya akun, iklan, atau pelacak. Data pribadimu tinggal di perangkat, dan fitur yang menyentuh data sensitif (kamera, mikrofon, memory, cloud, isi notifikasi, mic selalu aktif) mati sampai kamu menyalakannya sendiri.

Siapa yang bertanggung jawab

SmartEyeX dikembangkan oleh XNVA Labs, proyek pengembang independen. Pertanyaan soal privasi: [ISI: email kontak].

Data di perangkat tidak ikut dicadangkan ke cloud karena fitur backup aplikasi dinonaktifkan.

Pihak ketiga

  • Penyedia model AI. Server XNAI meneruskan pesan, teks terjemahan, dan foto ke Anthropic (API Claude) untuk menghasilkan jawaban. Penyedia ini memproses data sesuai kebijakannya sendiri. [Perbarui bagian ini jika penyedia diganti.]
  • Layanan Android. Pengenalan suara, suara balasan (text-to-speech), dan aplikasi peta dijalankan oleh komponen sistem atau aplikasi lain di perangkatmu.
  • SmartEyeX tidak memuat SDK iklan, analitik, atau pelacakan.

Apa yang dilakukan server XNAI

Server hanya meneruskan permintaanmu ke penyedia model AI dan mengembalikan hasilnya. Server tidak menyimpan isi pesan, foto, atau hasil di basis data. Jawaban disimpan sementara di memori sekitar 5 menit agar percobaan ulang tidak diproses dua kali, lalu hilang. Log teknis hanya berisi metode, alamat endpoint, status, dan durasi, tanpa isi. Alamat IP dipakai sebentar di memori untuk membatasi penyalahgunaan; penyedia hosting dapat mencatat metadata jaringan standar.

Kendalimu

  • Matikan Mic selalu aktif kapan saja lewat tombol di notifikasinya, ketukan VOICE di layar XNAI, atau ucapan “SmartEyeX matikan mic”.
  • Matikan kamera, mikrofon, memory, cloud, isi notifikasi, atau personalisasi suara kapan saja di Privacy Control. Mematikan Memory atau Voice Personalization menghapus data terkait.
  • “Hapus semua memori & reset izin” menghapus memory, jadwal, kontak, materi belajar, tugas, personalisasi, dan feed notifikasi, lalu mengembalikan semua izin ke OFF.
  • Cabut izin Android (kamera, mikrofon, notifikasi, Notification Access, alarm) kapan saja dari pengaturan sistem.
  • Menghapus aplikasi menghapus semua data lokalnya. Karena tidak ada akun, tidak ada data tersimpan di server untuk dihapus.

SmartEyeX tidak meminta akses lokasi, daftar kontak, atau panggilan telepon langsung.

Keamanan

Semua komunikasi ke server memakai HTTPS. Kunci enkripsi data lokal disimpan di Android Keystore. PIN dibatasi percobaannya dan terkunci sementara setelah beberapa kali salah. Tidak ada sistem yang sepenuhnya aman; jika kamu menemukan celah, kabari lewat email di atas.

Anak-anak

SmartEyeX tidak ditujukan untuk anak di bawah 13 tahun, dan kami tidak dengan sengaja mengumpulkan data dari mereka.

Perubahan kebijakan

Jika praktik data berubah, halaman ini diperbarui dengan tanggal baru sebelum perubahan itu berlaku di versi aplikasi yang dirilis.
